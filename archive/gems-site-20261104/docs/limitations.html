1. Data blocker (single remaining blocker to end-to-end scoring)

Run on any unrestricted machine with DrivenData credentials:
bash scripts/download_competition_data.sh (documents placement)
python scripts/prepare_data.py (verifies data/raw/ and writes data/grid_contract.json)
Then the full pipeline runs: evaluate_holdout.py → leakage canary → uniqueness check → submission_writer.py → validated TIF → JSON run card.
  • training_features.tif, labels.tif, sample_submission.tif, existing_faults.tif, 1m_DEM_links.csv require DrivenData login; the official data page redirects to login without auth.

  • Until data is in place, no weekly DrivenData submission slot should be spent (protocol cap respected: 0 slots spent this session).
