Source hierarchy used

  1. Regulator and statute first. CSLB licence records for every contractor field; leginfo for BPC §7048, BPC §7057 and Civil Code §1954; SF.gov/DBI for the permit rule and permitted licence types.
  2. Manufacturer documentation for how the product is built and serviced.
  3. Code guidance from IAPMO for the access-panel clause, with the caveat that the authoritative text is the adopted code itself.
  4. Never: directories, aggregator ratings, or search-result snippets as a substitute for the official page. Where a platform blocked retrieval, the field is blank.
