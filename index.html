How to submit on DrivenData

  1. Enroll: click “Compete!” at DrivenData competition page.
  2. Download competition data (login required): training_features.tif, labels.tif, sample_submission.tif, 1m_DEM_links.csv → data/, then python scripts/prepare_data.py.
  3. Conform this TIF to the training geometry and validate: python scripts/validate_submission.py submissions/FILE.tif data/labels.tif. It must pass: values in [0,1], no NaN inside the footprint, CRS/shape/transform match.
  4. Submit → Make new submission → choose the .tif → add a short note (e.g. “clustering with k=25”) → submit.
  5. Select ONE final submission before Dec. 3, 2026, 10 p.m. UTC. Limit: one scored submission per UTC day.
