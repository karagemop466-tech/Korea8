What the build enforces

  • Source per row. The build refuses to publish a row that has neither a source link nor an explicit owner-provided / unverified marker.
  • Blank instead of inferred. Any value that could not be read from the linked official source is empty, and the row is listed on Flagged for review.
  • Internal links. Every relative link in the generated pages is resolved against the generated file set; the build fails on a broken link.
  • One source of truth. All pages are generated from site-data/*.json; no page is hand-edited.

How to re-run

python3 scripts/build_canonical_site.py
python3 scripts/verify_canonical_site.py

The verifier re-checks the generated HTML independently of the builder and writes site-data/verification.json.

What is not verified

  • Quote amounts and the work history they imply (F-02, F-03).
  • Whether any listed firm has done this exact repair through a ceiling below an occupied unit (F-09).
  • San Francisco Plumbing Code §104.2 and CPC §402.10 text (F-07).
  • Review ratings — deliberately not published (F-04).
  • Whether this specific job needs a permit, until a contractor or DBI says so in writing (F-15).
