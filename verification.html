How a row is allowed onto this site

  • Official source first. Every licence row links to the CSLB licence-detail page it was read from; every rule row links to the statute, the CSLB classification page, or the San Francisco DBI page that states it.
  • Blank beats guessed. If no source on the row states a value, the cell is rendered blank with a pointer to the Flagged for Review page. No value is inferred, averaged, rounded or carried over from a third-party directory.
  • Owner-supplied data stays labelled. The three quotes come from the owner's own outreach and sit in a column marked owner-supplied; the official-confirmation field is blank because no official register records private quotes.
  • Dates are per row. Every table says when its source was read, so a stale row is visible rather than hidden.
