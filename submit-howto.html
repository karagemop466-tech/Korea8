Before you submit

  1. Download the format-verified TIF from the home page: docs/downloads/korea8-k8-1-blind-stepper-relay-20261104-v1.tif.
  2. Confirm it passed validation: single-band float32 GeoTIFF, 3730 × 3292, EPSG:32611, 100 m, values in [0, 1] inside the footprint, no NaN inside the footprint (0 NaN found; values in [0, 0.82]).
  3. Use the submission name and note exactly as recorded in run_card.json (note must be ≤ 140 characters — ours is 133).

Submission steps on DrivenData

  1. Go to the GEMS Prize Challenge submission page: https://www.drivendata.org/competitions/306/competition-doe-gems/ (log in with your DrivenData account).
  2. On New submission, choose File to submit and upload the Korea8 TIF (or a .zip containing only that GeoTIFF).
  3. Enter the Note (optional but recommended): K8-1 blind stepover/relay conduit lane: off-catalogue near-field geophysical-edge targets; not dotted catalogue traces. Format-valid. (133 characters ≤ 140 max).
  4. Click Submit.
  5. Check the receipt. If you see "Predicted values must be in range [0, 1]", the file has NaN or out-of-range values inside the footprint — re-download the Korea8 TIF (pre-verified) rather than editing it.
  6. Record the organiser-confirmed score from the submission-page receipt; label it ORGANIZER-CONFIRMED in your records (never mix it with HOLDOUT-DTI projections).
