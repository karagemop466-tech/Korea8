lowF-13

B-only licences would have to subcontract the plumbing

Licences 1106131 (SF BUILDING GROUP, B only) and 300647 (CAHILL CONTRACTORS INC, A + B, licensed since 1974, no C-36) cannot do the plumbing in house. Under BPC §7057(b) a B contractor may take the prime contract on a two-trade job but must subcontract an appropriately licensed contractor for the trade it does not hold.

Effect. Either firm could be the single point of contact, but not a single crew.
Action. If either is approached, require the plumbing subcontractor's licence number in the quote.

mediumF-16

Whether a ceiling access panel is required depends on a joint nobody has seen

UPC §402.10 requires a 12-inch access panel only where a slip joint is concealed; soldered or two-piece joints do not trigger it. The joint type behind this wall is unknown until the assembly is opened, so the code answer is conditional.

Effect. A solid patch may or may not comply, depending on what is found.
Action. Specify a framed access panel in the quote so the result complies either way, and have the contractor photograph the joint while it is open.

lowF-19

The access-panel section number differs between code editions

The concealed slip-joint access-panel rule is cited as UPC §402.10 in the edition IAPMO documents, while some California Plumbing Code editions place the same requirement under different numbering. The substance (a 12-inch access panel or utility space for concealed slip joints) is unchanged; only the citation moves. Recorded by the preceding integration pass.

Effect. A contractor quoting a different section number is not necessarily wrong.
Action. Cite the requirement itself, not only the number, when specifying the ceiling detail.
