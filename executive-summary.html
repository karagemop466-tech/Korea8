Executive summary — GEMS Prize Challenge submission pipeline

Korea8 · branch arena/057f3280-korea8 · U.S. DOE / National Lab of the Rockies via DrivenData · Deadline Dec. 3, 2026, 10 p.m. UTC

1. The task

Submit one single-band GeoTIFF (.tif) of fault probability (values in [0, 1]) matching the training data's CRS (EPSG:32611), resolution (100 m), shape and geotransform. Score = distance-weighted Tversky index (DTI, α=0.2, β=0.8, triangular kernel R=300 m). Limit: one scored submission per UTC day per person.

2. How to make a submission

  1. Enroll via "Compete!" at DrivenData.
  2. Download competition data (login required): training_features.tif, labels.tif, sample_submission.tif, 1m_DEM_links.csv → data/; run python scripts/prepare_data.py.
  3. Generate/validate: python scripts/generate_submission.py then python scripts/validate_submission.py submissions/FILE.tif data/labels.tif (this catches the "Predicted values must be in range [0, 1]" error before upload).
  4. On DrivenData: Submit → Make new submission → choose .tif → add a short note (≤140 chars, e.g. "clustering with k=25") → submit.
  5. Select ONE final submission before the deadline; it is scored in both prize rounds.

3. PhD-level assessment: GEMSDOE32 "h33-h33-2-b2-...-zeros: 0.2778"

Why it scored 0.2778 — it (almost certainly) didn't, under the official metric.

Under the official distance-weighted Tversky index (α=0.2, β=0.8), an all-zero prediction over the whole footprint gives TPw = 0, FPw = 0, FNw = (number of ground-truth pixels), so DTI = 0 exactly. A "-zeros" file scoring 0.2778 is incompatible with the official DTI unless the file is not actually all zeros or a different label set/metric was used.

  • The GEMSDOE sites are third-party participant documentation sites; their scores are self-reported, NOT Organizer-confirmed DrivenData receipts.
  • GEMSDOE32 now returns 404 (buffedlizard55-lab.github.io/GEMSDOE32/docs/index.html), so its raster and receipt cannot be inspected or verified.
  • The "-zeros" suffix may be a label, not a description of file content.

Can we beat 0.2778? Yes — with a geologically-informed, holdout-validated prior (dilatational stepover/relay zones; strain×heat-flow×seismicity intersections; radiometric edges; paleo-geothermal halos) that beats the holdout best and passes the format validator. No slot may be spent until holdout DTI + 95% CI exceeds the target (one scored submission per UTC day).

A projection is never written as a score. In this summary all GEMSDOE site scores are THIRD-PARTY SELF-REPORT; our TIF has no score yet (holdout not runnable without data).
