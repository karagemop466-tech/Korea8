# Canonical dashboard data

`dashboard.json` is the current source of truth for the root bathtub-repair dashboard.
`python scripts/build_canonical_site.py` generates the static pages from it; the earlier
JSON files in this directory are retained as superseded integration records. They are not
used to generate the current dashboard.

License and business-contact information is a dated CSLB snapshot and must be rechecked
before engagement. The requirements are labeled by origin. Links in first-party requirement
rows provide relevant official context, not independent evidence of the request. Review
accounts are attributed to the platform and are not proof of this specific job.
