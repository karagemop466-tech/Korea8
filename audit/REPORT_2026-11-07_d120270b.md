   blank/unverified marker; every internal link must resolve; independent privacy-phrase scan;
   amount-label scan.
2. Run the site's own verification stack as a cross-check (`scripts/verify_overflow_site.py`,
   `scripts/verify_canonical_site.py`, `tests/test_overflow_site.py`).
3. Re-read primary sources directly (CSLB licence-detail pages, California statutes, sf.gov/DBI,
   the official fee-schedule PDF) and compare them field-by-field with what the site publishes.
4. Fetch the live GitHub Pages site with cache-busting query strings and compare counts/content
   with the audited revision.
5. Privacy sweep of every served file (pages, JSON data, scripts).
