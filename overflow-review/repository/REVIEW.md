# Repository review — 2026-11-07

## Method and boundary

Every tracked file was inventoried with its byte count and SHA-256. Every decodable text file was scanned line by line for UTF-8 validity; JSON files were parsed and Python files syntax-parsed. The machine-readable result is `inventory.json`. This is a structural/provenance audit, not a claim that unrelated geothermal research was experimentally reproduced.

The current plumbing brief was checked against official regulator, statute, manufacturer and company-published sources. Earlier plumbing assertions were treated as leads, not proof. Unsupported quote amounts, review figures, exact-job acceptance and availability are not adopted.

## Irregularities for review

1. **Mixed repository purpose.** DOE GEMS research, evidence and large raster artifacts coexist with the plumbing brief. They are preserved, not silently repurposed or scientifically revalidated.
2. **Many overlapping dossiers.** Root pages, `project/`, `site-data/`, `bathtub/`, `bathtub-overflow/`, `bathroom-overflow/`, `trip-lever/`, `overflow-trip-lever/` and `docs/bathtub-*` contain different counts and wording. The root is the intended canonical public route; superseded routes must not expose unsupported values.
3. **Unsupported prices in legacy files.** Earlier drafts display owner-supplied amounts as facts or benchmarks. The new dataset leaves amount and commercial-term cells blank until provider-issued confirmation exists.
4. **Overstated license conclusions.** A B classification is conditional authority, not proof of drywall skill or exact-job acceptance. Shared address/phone does not establish common ownership. C-36-only records do not establish a combined plumbing/drywall contract.
5. **Review evidence limitations.** Yelp direct retrieval is blocked; search excerpts change. Numeric ratings/counts are blank in the new dataset. Review links are discovery aids, not licensing evidence.
6. **Manufacturer and code limits.** Watco instructions apply to identified Watco families, not an unknown tub. The IAPMO access spotlight is based on the 2018 UPC and expressly disclaims official interpretation; current local application is not asserted.
7. **Company-page soft 404.** Heise’s project articles render useful project text but embed an unrelated 404 template. The article is company-published evidence, not an independent quality guarantee.
8. **Official adverse/additional statuses.** Kenneth Asire #1027286 is suspended; Advanced #1009195 has a future-suspension warning; D G #297604 has complaint disclosure. These are separated from ordinary active candidates.
9. **Deployment evidence mismatch.** The latest observed legacy run’s build job succeeded while deployment failed after about ten minutes. A merge or generic Pages status is not proof the new content is live. The final workflow must check build, deployment and page content.
10. **Parallel integrations.** Main advanced during this session and another integration PR became active. Shared files were not edited during that active claim. The board conflict was resolved by retaining both histories.
