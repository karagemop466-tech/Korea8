Latest findings (quick view)

Preferred access is from above if the stuck assembly can be freed without damaging hidden plumbing; all plumbers contacted recommend working from below, through the ceiling of the storage unit beneath the tub. That path requires opening the ceiling drywall — a vendor with both C-36 plumbing and B building licensure (or a plumber + drywall pair) is preferred. Tenants occupy the unit; work must be dust- and noise-conscious.
