This page summarizes the problem, options, analysis, and recommendation. Detail tables live on the Estimates, Candidates, and Requirements pages.

The problem

The bathtub overflow — the trip-lever waste-and-overflow assembly — is stuck inside the hidden plumbing behind the wall, in a hard-to-access area. More than five licensed plumbers have been unable to remove it from above without concern over destroying the hidden plumbing behind the wall. All of them recommend working from below: there is a storage unit below the tub, and accessing the hidden plumbing may require opening the drywall ceiling of that storage unit. The unit is occupied by tenants, so the work must be performed delicately in a sensitive environment.
