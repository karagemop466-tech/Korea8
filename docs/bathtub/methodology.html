Verification policy

  • Every table row carries a source link to an official site, a public listing, or is blank.
  • If a value can be confirmed from an official source, it is marked Verified and linked.
  • If a value cannot be confirmed from an official source, it is left as recorded, marked Unverified, flagged FLAGGED FOR REVIEW, and never inferred or filled in.
  • No values are invented. User-provided items (estimates, access preferences, observations) are recorded exactly as provided and flagged.
  • Private information: the requester’s reasons for not pulling a permit this week are never recorded in the repo, on the site, or in any communication.
